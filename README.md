# Liquid Glass Argon Theme

以 Argon 為基礎的 WordPress 部落格主題。首頁以全幅桌布襯托玻璃卡片，文章頁使用較不透明的底色，方便閱讀長文。

## 安裝與配色

1. 在 WordPress 後台開啟「外觀 → 佈景主題 → 安裝佈景主題 → 上傳佈景主題」。
2. 上傳 `liquid-glass-1.1.3.zip` 並啟用。主題需要 WordPress 6.2 以上及 PHP 8.0 以上。
3. 在後台「Liquid Glass」選擇暖色或粉色作為網站的預設玻璃配色。也可以調整主題色、淺色與深色背景，以及首頁和側欄版型。

讀者可用頁首的水滴按鈕切換粉色，也可用月亮按鈕切換深色。粉色支援淺色與深色，並儲存在目前的瀏覽器。要自行指定其他主題色，可從頁面下方的設定按鈕開啟色彩選擇器。

## 玻璃效能

首屏先使用輕量毛玻璃。瀏覽器空閒後檢查硬體 WebGL，支援時會在停下捲動後繪製邊緣折射。動態折射會等到實際量測有餘裕才開啟；持續掉幀時會先停用捲動中的折射，必要時退回毛玻璃。自動判斷結果保留 30 分鐘供再次造訪使用。

點頁尾「輕量模式」可手動關閉折射，設定會記在目前的瀏覽器。再點一次會恢復自動判斷。瀏覽器不支援 WebGL，或自訂背景網址無法提供跨來源圖片存取時，會使用 CSS 毛玻璃。使用獨立背景圖的 Banner 會保留對應自身圖層的 CSS 毛玻璃。

## 管理設定

後台「Liquid Glass」按用途切分設定。切換分類與儲存可原地完成，其他分類尚未儲存的輸入會留在目前頁面。也可匯出 JSON 或匯入既有 Argon 備份。「文章與說說」的讚賞設定可從媒體庫選圖或貼上圖片網址，選填的讚賞連結會套用在 QR Code。頁尾附加內容可在「側欄與頁尾」編輯，換行會反映在前台。文章圖片使用 WordPress 原生的延遲載入與響應式圖片，Performance Lab 的圖片功能可另外搭配使用。

## 首頁說說與文章列表

- 訪客可以在首頁「最新文章」旁切換「顯示說說／隱藏說說」。文章列表會原地更新，選擇隨網址一起保留，翻頁時繼續生效。
- 站長可在「Liquid Glass → 文章與說說 → 首頁說說預設顯示」調整初次造訪的狀態。「說說」專頁可獨立瀏覽。
- 在區塊編輯器按「＋」搜尋「文章列表」，即可將列表放進文章、頁面或支援區塊的小工具區。可調整篇數、分類、排序、摘要和特色圖片。
- 多欄文章列表按卡片高度接續排列。當欄尾相差較多時，頁末幾張卡片會重新分欄，分頁列顯示在整個瀑布流下方。

## 從 Argon 切換

Liquid Glass 安裝在獨立的 `liquid-glass` 主題目錄。它沿用 Argon 的文章欄位、設定、選單位置、小工具位置、短代碼和「說說」文章類型。既有的留言板、歸檔時間軸與說說頁面會繼續使用原本的頁面範本。也可以在「Liquid Glass」切換至原有的三種文章卡片版型。

主題預覽圖使用測試文章。安裝時會直接讀取 WordPress 中的文章和頁面。
